One sentence, at most 200 characters, that makes a small everyday moment
strange and new — an entry for the make.fun bounty
[Everyday Wonder, Two Days to Find the Line](https://make.fun/c/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3).

## The entry

> The escalator handrail moves faster than the steps, so for thirty seconds my hand is travelling without me.

## How it works

`main.py` writes the sentence to `/output/entry.txt`:

```sh
python3 main.py
```

The output is a single sentence of 107 characters, within the 1–200 character gate.
